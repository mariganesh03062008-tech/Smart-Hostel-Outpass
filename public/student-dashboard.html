Understanding Outpass Workflow Stages

Each outpass request follows strict hostel security protocols to ensure student safety and academic accountability:

1

Normal Outpass: Student → Parent → Warden

Status: Pending Parent → Pending Warden. Requires parental consent before Warden authorization.

2

One-Day Duty: Student → Class Advisor → Principal

Status: Pending Advisor → Pending Principal. Academic clearance with Principal final sign-off.
